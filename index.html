Sobre Mí

¡Hola! Soy Humberto. Apasionado por la tecnología y la resolución práctica de problemas, me encuentro enfocado en el desarrollo web moderno, combinando la construcción de interfaces atractivas con HTML5, Tailwind CSS y JavaScript, junto con una sólida lógica en el backend y control de versiones con Git y GitHub.
